### 数据格式

导出的 JSON 格式内容与原始 API 提供的内容基本相同。

- 导出文件中不提供 error、copyright、version、format 等字段。
- 某些字段的值格式在导出中可能会有所不同，这主要是由于爬虫更新和过时的爬取缓存所致。

如果当前的静态导出中没有相应的站点数据，您可以尝试访问原始 API 作为回退来自动生成它。
